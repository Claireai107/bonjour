# 모델 변수 정정 — 임신 횟수 · 음주 시작 나이 (v1.4.0)

## 어디서 나온 이야기인가

1차 UT에서 P3가 "임신 한 번"이라고 말했는데 인식이 안 됐다는 기록이 있었다.
그런데 저장소의 설문에는 임신 문항이 없었다. DA에게 확인한 내용:

> `LW_pr_1`(임신횟수)은 유산·자궁외임신·현재 임신까지 포함한 총 임신 횟수이고,
> 출산(`LW_mt`)과는 다른 문항·다른 변수입니다.
> 관계식: 임신횟수 ≥ 출산횟수. 둘을 같은 값으로 쓰면 안 됩니다.

이 말을 듣고 코드를 다시 보니 문제가 두 개 있었다.

## 문제 1 — 라벨이 틀려 있었다

`lib/predict.ts` 의 화면 표기 표에 이렇게 적혀 있었다.

```ts
LW_pr_1: "출산 횟수",   // ← 틀림
```

리포트의 "점수에 영향을 준 항목"에 그대로 나오는 이름이다.
DA 설명대로 `LW_pr_1` 은 임신 횟수이고 출산 횟수(`LW_mt`)와는 다른 변수다.
**"임신 횟수"로 고쳤다.**

## 문제 2 — 값을 안 묻고 중앙값을 넣고 있었다

```ts
BD2: undefined,      // 앱 미수집 → 학습 중앙값 대체
LW_pr_1: undefined,  // 앱 미수집 → 학습 중앙값 대체
```

모든 사용자에게 **임신 4회 · 음주 시작 35세**가 들어가고 있었다.
기획서의 설문 10개 변수 목록에는 두 항목이 다 들어 있는데, 앱은 안 묻고 있었다.

계수를 놓고 계산해 보면 이 정도 차이가 난다 (로그오즈 기준).

| 임신 횟수 | 중앙값(4회) 대비 |
|---|---|
| 0회 | +0.274 (위험 ↑) |
| 1회 | +0.205 |
| 2회 | +0.137 |
| 6회 | −0.137 (위험 ↓) |

| 음주 시작 | 중앙값(35세) 대비 |
|---|---|
| 18세 | −0.181 |
| 25세 | −0.107 |
| 45세 | +0.107 |
| 60세 | +0.266 |

임신 경험이 없거나 적은 사람일수록 위험이 낮게 나오고 있었다는 뜻이다.
40대 사용자에게 특히 불리하게 어긋난다.

## 무엇을 바꿨나

**설문 2문항 추가** (총 10 → 12문항, `TOTAL_STEPS` 도 함께 수정)

- **7단계 임신 횟수** — 숫자 입력 0~15, 기본 2.
  안내 문구: "유산이나 자궁외임신도 함께 세어 주세요. 없으면 0이에요"
  음성으로 "없어요 / 한 번 / 세 번"을 받는다 (`countStyle: true`).
- **10단계 음성 시작 나이** — 선택형 5개.
  안 마셔요(−1) / 20세 이전(18) / 20대(25) / 30대(35) / 40세 이후(45).
  KNHANES `BD2` 는 연속값이지만 시니어가 정확한 나이를 떠올리기 어려워
  구간 대표값으로 받는다. **안 마시는 경우는 중앙값 대체를 유지한다** —
  술을 안 마시는 사람에게 특정 시작 나이를 부여할 수 없기 때문이다.

**개인정보 처리방침**의 수집 항목도 "출산 경험" → "임신 횟수"로 고쳤다.
실제로 수집하는 항목과 고지 내용이 어긋나면 안 된다.

**테스트** — `tests/predictVars.test.mjs`

- 임신 횟수를 넣으면 결과가 달라지는지, 방향이 맞는지(많을수록 위험 ↓)
- 미입력 시 중앙값 대체가 0회와 6회 사이에 놓이는지
- 술을 안 마시는 경우(−1)가 미입력과 같은 결과인지
- 요인 이름에 "출산 횟수"가 다시 나타나지 않는지

`tests/resolveTs.mjs` 는 테스트에서만 쓰는 모듈 해석 도우미다.
앱 코드가 `import "./modelParams"` 처럼 확장자를 생략해서 node 가 못 찾는데,
빌드 설정을 건드리지 않으려고 테스트 쪽에만 붙였다.

## 확인이 필요한 것

- **수면시간(`sleepHours`) 문항은 어디에도 쓰이지 않는다.** 모델 변수도 아니고
  운동 추천 로직에도 안 들어간다. 문항이 12개로 늘어난 만큼, 뺄지 남길지
  정하는 게 좋겠다. 일단은 그대로 뒀다.
- 임신 횟수는 민감한 질문이다. 건너뛰기를 넣을지, 어느 위치에 둘지는
  팀에서 한 번 보는 게 좋겠다. 지금은 초경 연령 바로 다음에 뒀다.
- 음주 시작 나이를 구간이 아니라 정확한 나이로 받을지도 결정이 필요하다.
